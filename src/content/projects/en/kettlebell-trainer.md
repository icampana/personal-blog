Web application for designing and tracking kettlebell and dumbbell workouts, built to solve friction during actual training:

- **Smart Generator**: Safe sequence algorithm based on position transition matrices (floor, rack, overhead, ballistic, and grind).
- **Gym / Compact Mode**: High-density checklist view with interactive checkmarks for real-time tracking without excessive scrolling.
- **Quick Export**: One-click plain-text copy formatted for messaging and notes apps, plus print and PDF styling.
- **Non-blocking Rest Timer**: Circular countdown timer that minimizes to a floating pill so you can preview upcoming exercises during rest intervals.

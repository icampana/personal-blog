Aplicativo web para planejamento e execução de treinos com kettlebells e halteres:

- **Gerador Inteligente**: Sequências baseadas em matriz de transição de posições biomecânicas.
- **Modo Academia / Compacto**: Visualização em tabela de alta densidade com lista de verificação para treino ativo.
- **Exportação Rápida**: Cópia em texto formatado para mensageiros ou notas, além de layout para impressão e PDF.
- **Cronômetro Não Bloqueante**: Temporizador minimizável para consultar os próximos exercícios durante o intervalo.
